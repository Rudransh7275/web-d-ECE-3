Core Module Descriptions

HTML5
The standard markup language used to structure content and layout on a web page.
CSS3
The style sheet language used to describe the presentation and design layout of a document.
JavaScript
A powerful scripting language used to create dynamic and interactive elements on websites.

Learning Pathways

Prerequisites

  • Basic computer literacy and typing proficiency.
  • A modern web browser installed (Chrome, Firefox, or Edge).
  • A code editor setup (VS Code is recommended).

Weekly Progression

  1. Introduction to Internet Protocols and Web Architecture.
  2. Structuring text elements, tables, and multimedia content.
  3. Deploying static pages to free cloud hosting platforms.

Detailed Weekly Breakdown (Mixed & Nested Lists)

  1. Week 1: Foundations of HTML
    • Introduction to Elements & Attributes
    • Working with Text Formatting:
      1. Bold and Italic tags
      2. Underline and structural blocks
    • Using HTML Character Entities (<, >, &)
  2. Week 2: Advanced List Management
    • Creating standard Numbered Sequences (<ol>)
    • Creating Bulleted Directories (<ul>)
    • Implementing Definition Lists (<dl>)
  3. Week 3: Project Milestone 1
    • Designing a semantic resume page
    • Submitting code via version control
